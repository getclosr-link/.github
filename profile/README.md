### Get involved

- **Feedback:** turn on the *Send feedback* switch at the bottom of [getclosr.link](https://getclosr.link). It stays private and is never published automatically.
- **Code and ideas:** read [CONTRIBUTING.md](https://github.com/getclosr-link/getclosr/blob/main/CONTRIBUTING.md), then open an issue or a pull request in [getclosr](https://github.com/getclosr-link/getclosr).
- **Security:** report anything that could expose someone's answers privately, as described in [SECURITY.md](https://github.com/getclosr-link/getclosr/blob/main/SECURITY.md).
